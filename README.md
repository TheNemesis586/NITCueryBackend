# NITCuery: Backend

This is the backend section of the NITCuery app to be used by the National Institute of Technology - Calicut campus.

This will handle all database operations and functionality for the MFRC522 RFID reader/writer to be used with all Raspberry Pi models with Python 3 support and the kernel/python modules required to make the scanner functional.
